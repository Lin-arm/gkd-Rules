## 📑说明

> [!IMPORTANT]
> 本订阅仅供学习交流使用，请勿做非法用途

- 目前主要研究 `ks` , `ks极速版` , `zfb(蚂蚁🌲🐤)` , `7.读📚` 等应用的规则, 如有遇到失效规则, 请提交 [Issues](https://github.com/Lin-arm/gkd-Rules/issues/new/choose)。

- 另外 订阅后请进`应用规则`里，再逐个进app里斟酌是否需要关闭某条规则, 本订阅的规则大部分默认是开着的。
